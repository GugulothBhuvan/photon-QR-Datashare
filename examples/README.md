# Examples

Runnable, self-contained demonstrations of individual subsystems, used as
executable documentation.

Each example depends only on the layer it demonstrates, so it doubles as a
check that the layer is genuinely decoupled from the rest of the system.

Planned:

- `packet-roundtrip/` — serialize and deserialize a packet (Phase 3)
- `protocol-simulation/` — drive a transfer without camera or display (Phase 4)
- `qr-encoding/` — render a packet as an optical frame sequence (Phase 5)
