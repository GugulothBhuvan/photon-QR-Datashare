# Scripts

Developer and CI tooling. Scripts are executable utilities only — they must
never become a home for protocol or application logic, which belongs in
`src/core` and `src/services`.

Packet vectors are generated by the suite that verifies them rather than by a
script here — see `test_vectors/README.md`. That keeps the generator and the
checker from drifting apart, and avoids a TypeScript-executing dependency for
one file.
